Wasmageddon

A browser-native multiplayer grid arena

Wasmageddon is an independent WebAssembly port built from the open-source Armagetron Advanced project, bringing its multiplayer arena gameplay to desktop and mobile browsers.

  • Discord — community, matches and playtests
  • Source code on GitHub — the exact source this build was made from
