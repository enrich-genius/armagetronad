Wasmagetron

A browser-native multiplayer grid arena

Wasmagetron is an independent WebAssembly port built from the open-source Armagetron Advanced project, bringing its multiplayer arena gameplay to desktop and mobile browsers.

  • Discord — community, matches and playtests
  • Source code on GitHub — the exact source this build was made from
  • Licensing — GPL-2.0-or-later, and how to reproduce this build
  • Contributing — help port open-source games to WebAssembly

Armagetron Advanced is the work of its own authors and contributors. Wasmagetron is not affiliated with, nor endorsed by, the Armagetron Advanced project, Disney, or any Tron rights holder.
